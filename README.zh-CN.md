## 软件简介

Html-PPT-Editor 专为使用 AI 工具生成 HTML 演示文稿的用户打造。基于 Rust + WebView2，赋予你修正、美化、增强 AI 生成内容的能力，让每一份演示都专业、安全、流畅。

> **核心定位**：AI 生成 HTML 演示文稿的最佳编辑伙伴

### ✏️ 可视化编辑

所见即所得的编辑体验，无需手写代码。选中文字即可调整样式（加粗、斜体、下划线、删除线）、切换标题级别（H1/H2/H3）、调整对齐方式。支持直接插入图片、视频、在线视频和超链接。

> ⚠️ **操作提示**：打开 HTML 文件后，需点击侧边栏的 **"编辑"按钮**，方可激活编辑模式并显示工具栏。再次点击可退出编辑模式，预览区恢复只读状态。

### 📄 源码编辑

420px 宽的代码编辑面板，等宽字体排版，修改后预览区实时更新。满足技术用户对每一行代码的精细控制需求。

### 🔍 预览与缩放

CSS transform 实现流畅缩放（25% — 300%，每次 ±10%），一键 1:1 复位，不影响编辑操作。

### 📊 幻灯片导航

自动识别 HTML 中的幻灯片标记，支持 **8 种**标记方式（`.slide`、`.slide-page`、`.page`、`<section>`、`<article>`、`data-slide`、`data-page`、`hr.separator`），顶栏实时显示当前位置。Free 版每日最多 20 张幻灯片。

### 🎬 全屏演示模式

隐藏所有 UI 的沉浸式演示体验，纯黑背景 + 浮动控制条，支持键盘导航（← → ↑ ↓ Space Home End），所有 CSS 动效流畅呈现。退出后自动恢复侧边栏状态。

### 📥 文件操作

- 点击按钮或快捷键 Ctrl+O 打开
- 空白状态点击中央按钮
- **Pro 版**：从 URL 加载（SSRF 防护 + 反爬检测 + 频率限制）
- 一键保存（Ctrl+S），保存时自动移除预览水印

### 🎨 主题管理

内置 5 套精美主题（DeepLogiX Dark、Nordic Light、Midnight Blue、Forest、Monochrome），一键切换全局风格。Pro 版主题持久化保存，Free 版仅当前会话有效。

### 📋 页眉页脚管理

自动识别 `position: fixed/absolute` 的页眉页脚元素，支持显示/隐藏切换、HTML 内容编辑、图片替换。**注意**：不识别 `sticky` / `relative` 定位的元素。

### 🖼️ 媒体管理

支持插入和管理图片（PNG/JPG/GIF/WebP/SVG/BMP/ICO）、视频文件（MP4/WebM/MOV/AVI/MKV/M4V/OGG，单文件 ≤ 100 MB）、在线视频（YouTube/Bilibili/Vimeo 自动识别嵌入）和超链接。Free 版可使用 25%/50%/100% 预设尺寸，Pro 版可拖拽自定义尺寸并替换图片。

### 📤 导出功能

- **导出 HTML**（免费）：一键生成 `presentation.html` + `asset/` 目录，自动改写媒体路径为相对路径，移除水印与编辑器属性。
- **导出 PDF**（Pro 专属）：基于 `pdf-lib` 渲染，每张幻灯片 → 一张 PDF 页面（1920×1080），视频以海报图卡片占位。

## 下载与安装

### Windows

1. 从发布页下载 `.msi` 或 `.exe` 安装包
2. 双击运行安装程序
3. **系统保护提示**：Windows SmartScreen 可能弹出"Windows 保护了你的电脑"警告，这是因为软件暂无数字签名证书。点击 **"更多信息"** → 选择 **"仍要运行"** 即可继续安装
4. 安装完成后，从桌面快捷方式或开始菜单启动

### macOS

1. 从发布页下载 `.dmg` 安装包
2. 双击打开 DMG 文件，将应用图标拖入 Applications（应用程序）文件夹
3. **首次运行提示**：macOS Gatekeeper 会阻止未签名的应用直接运行，可能提示"无法验证开发者"。此时请：
   - 打开 **系统设置 → 隐私与安全性**
   - 向下滚动找到安全区域，点击 **"仍要打开"** 按钮
   - 在弹出的确认对话框中再次点击 **"仍要打开"**
   - 或者直接在 Finder 中右键应用 → 选择 **"打开"**，然后在弹出的警告中选择 **"仍要打开"**
4. 后续启动时不再拦截

### Linux

1. 从发布页下载 `.AppImage` 或 `.deb` 安装包
2. **AppImage 方式**：
   - 赋予执行权限：`chmod +x Html-PPT-Editor*.AppImage`
   - 双击运行或终端执行
   - 如果系统提示"无法执行"，请右击文件 → 属性 → 权限 → 勾选"允许作为程序执行文件"
3. **Deb 方式**：双击 `.deb` 文件或使用 `sudo dpkg -i *.deb` 安装
4. 从应用菜单或终端启动

## 安全与许可证

- **离线许可证**：无需联网激活，许可证本地存储于 `license.dat`
- **加密存储**：AES-256-GCM + HKDF-SHA256
- **签名验证**：RSA-2048 + PKCS#1 v1.5 + SHA-256，每次启动验签
- **设备绑定**：基于系统 UUID / machine-id 的 SHA-256 指纹
- **反调试**：7 层防护（IsDebuggerPresent、CheckRemoteDebuggerPresent、NtQueryInformationProcess、TracerPid、栈金丝雀、二进制自校验、时间异常）
- **审计日志**：所有许可证操作记录到 `audit.log`
- **时间回拨检测**：阈值 60 秒

许可证格式：`DPLX-v2.<base64url payload>.<base64url signature>`
